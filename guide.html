Sette passaggi, tutti fotografati su un Realme vero. Da fare una sola volta — dopo, ScreenSpan si ricorda tutto anche se riavvii il telefono.

Seven steps, all photographed on a real Realme phone. Do this only once — ScreenSpan remembers it even after a restart.

Testato suTested onrealme 14 Pro+ 5G · Android 16
Tempo richiestoTime neededcirca 2 minutiabout 2 minutes
1

Apri le informazioni sul telefono

Impostazioni→Informazioni sul dispositivo

Su realme si chiama così; su altri telefoni può essere "Info sul telefono" o "Sistema → Info". È sempre l'ultima voce dell'elenco principale.

Open the phone's device info

Settings→About device

That's the realme wording; other phones may call it "About phone" or "System → About". It's always the last item in the main list.

2

Tocca 7 volte il numero di versione

Versione→N. versione

Entra in "Versione", poi tocca ripetutamente la riga "N. versione" — non "Versione Android". Dopo qualche tocco compare un conto alla rovescia, poi la conferma.

Tap the version number 7 times

Version→Version No.

Open "Version", then tap the "Version No." row repeatedly — not "Android version". After a few taps a countdown appears, then a confirmation.

Fatto una volta, resta fatto: non dovrai ripeterlo nemmeno reinstallando l'app. Do it once and it stays done: you won't repeat it even if you reinstall the app.
3

Torna indietro e apri Opzioni sviluppatore

Impostazioni→Sistema e aggiornamento→Opzioni sviluppatore

La voce è comparsa solo ora, dopo il passo 2. Quello da attivare è "Debug wireless", qui ancora spento.

Go back and open Developer options

Settings→System & updates→Developer options

This entry only just appeared, after step 2. The one to turn on is "Wireless debugging", still off here.

4

Attiva Debug wireless

Debug wireless→interruttore ON

Serve una rete Wi-Fi accesa (basta la radio, non serve internet). Se compare "Collegati a una rete Wi-Fi", accendi il Wi-Fi e riprova.

Turn on Wireless debugging

Wireless debugging→switch ON

You need Wi-Fi turned on (just the radio, no internet required). If "Connect to a Wi-Fi network" appears, turn Wi-Fi on and try again.

5

Apri Debug wireless e scegli l'accoppiamento a codice

Debug wireless→Accoppia dispositivo con codice di accoppiamento

Non basta accenderlo: bisogna anche toccare la riga "Debug wireless" per entrarci. Dentro trovi l'indirizzo IP e due modi di accoppiare — usa quello col codice, non il QR.

Open Wireless debugging and choose code pairing

Wireless debugging→Pair device with pairing code

Turning it on isn't enough: you also need to tap the row "Wireless debugging" to go inside. There you'll find the IP address and two ways to pair — use the code one, not the QR.

6

Il telefono mostra un codice — ScreenSpan te lo chiede da solo

Non serve tornare nell'app: appena tocchi "Accoppia dispositivo con codice", ScreenSpan se ne accorge e manda una notifica con un campo pronto per il codice. Il codice cambia ogni volta — quello qui sotto è solo un esempio.

The phone shows a code — ScreenSpan asks for it on its own

No need to switch back to the app: the moment you tap "Pair device with pairing code", ScreenSpan notices and sends a notification with a field ready for the code. The code changes every time — the one below is only an example.

Codice di esempio Example code 7 2 1 3 4 6 6 7 5 2 2 4
7

Scrivi il codice nella notifica e invia

Digita le 6 cifre nel campo della notifica — senza uscire dalla schermata di Debug wireless, il codice scade se la lasci — e tocca la freccia blu. Fatto: il telefono è accoppiato.

Type the code into the notification and send

Type the 6 digits in the notification's field — without leaving the Wireless debugging screen, the code expires if you do — and tap the blue arrow. Done: the phone is paired.

Il codice ha una durata breve. Se scade, torna al passo 5 e ricomincia da "Accoppia dispositivo con codice" — è normale, basta un altro tentativo. The code is short-lived. If it expires, go back to step 5 and start again from "Pair device with pairing code" — that's normal, just try again.

Accoppiamento fatto — torna a ScreenSpan

Pairing done — go back to ScreenSpan

L'app se ne accorge da sola e spunta il passo. Se il telefono si riavvia dovrai solo riaccendere "Debug wireless" — l'accoppiamento resta, non va rifatto.

The app notices on its own and checks the step off. If the phone restarts you'll only need to turn "Wireless debugging" back on — the pairing itself stays, it doesn't need redoing.
